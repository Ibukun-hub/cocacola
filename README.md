Coca-Cola Zero Sugar Landing Page (Concept)

Overview

This project is a concept landing page created as part of a Meta Ads case study. It demonstrates how a high-converting landing page can be paired with Meta Pixel tracking to support a digital advertising campaign.

Disclaimer: This is an independent educational and portfolio project. It is not affiliated with, endorsed by, or created for The Coca-Cola Company.

Features

* Responsive landing page
* Modern, conversion-focused UI
* Call-to-action sections
* Customer testimonials
* FAQ section
* Clean HTML, CSS, and JavaScript
* Ready for Meta Pixel integration

Technologies Used

* HTML5
* CSS3
* JavaScript
